## 2. من هو المستخدم؟ (Target Users)

1. **المستخدم كثير الملفات على سطح المكتب (المطوّر، الباحث، المصمم، الطالب):**
   - تتراكم لديه الملفات الموؤقتة، اللقطات، المستندات، والمجلدات على سطح المكتب يوميًا، ويحتاج إلى ترتيبها بصريًا داخل صناديق مصنّفة مع إمكانية طيّها بنقرة واحدة.
2. **المستخدم ثنائي اللغة (العربية والإنجليزية):**
   - يعمل بملفات وملاحظات ومهام تجمع العربية والإنجليزية، ويعاني من برامج تنظيم سطح المكتب التي تفتقر لدعم محاذاة اليمين إلى اليسار (RTL) أو تكسر النصوص المختلطة.
3. **المستخدم العابر للأنظمة (Cross-Platform User):**
   - يستخدم ويندوز أو ماك أو لينكس (أو ينتقل بينها) ويريد نفس التجربة ونفس هيكل النسخ الاحتياطي المحلي دون قفل بياناته في نظام تشغيل واحد.
4. **المهتم بالخصوصية والأداء:**
   - يرفض رفع ملفاته أو ملاحظاته إلى سحابة خارجية، ويريد أداة خفيفة لا تستهلك الذاكرة أو المعالج في الخلفية.

## 3. ما يفعله المشروع (In Scope — Core Capabilities)

> *جميع القدرات التالية في حالة: **«لم يُختبر»***

### أ. صناديق تنظيم سطح المكتب (Desktop Boxes)
- **ربط المجلدات دون نقل قسري (Virtual Folder Mapping):** عرض محتويات أي مجلد على الجهاز داخل صندوق أنيق على سطح المكتب دون تغيير مساره الفعلي.
- **وضع الكبسولة (Capsule Mode):** طيّ أي صندوق إلى شريط صغير أنيق، ويتمدد عند التمرير (Hover) أو النقر (Click) حسب اختيار المستخدم.
- **مجموعات الصناديق (Box Groups / Tabs):** دمج عدة صناديق في إطار واحد مبوّب للتنقل بينها بسرعة.
- **محرك الفرز الآمن بلمسة واحدة (Safe Auto-Organizer):**
  - اقتراح تصنيف الملفات المبعثرة على سطح المكتب حسب النوع أو الامتداد أو التاريخ.
  - عرض **معاينة كاملة (Dry-Run Preview)** قبل لمس أي ملف.
  - النقل عبر نسخ الملف أولًا، التحقق من تطابق البصمة (`SHA-256` أو الحجم)، وتسجيل العملية في سجل تراجع (`Undo Log`) يتيح استعادة كل ملف لمكانه الأصلي بنقرة واحدة.

### ب. كبسولة الشاشة العلوية (Top Capsule / Island)
- شريط كبسولي صغير أعلى الشاشة (أو على حافتها) يتمدد بسلاسة ليقدم:
  - **درج الوصول السريع (Quick Shelf / Drop Zone):** إسقاط ملفات مؤقتة لتجميعها قبل نقلها إلى مجلد آخر.
  - **مؤقت التركيز (Pomodoro / Focus Timer):** جلسات تركيز مرتبطة بمهمة حالية.
  - **الالتقاط السريع (Quick Capture):** حفظ فوري للملاحظات القصيرة، الروابط، أو المقتطفات النصية.
- يختفي تلقائيًا عندما يدخل المستخدم في وضع ملء الشاشة (فيديو، عرض تقديمي، ألعاب).

### ج. البحث المحلي والوعي بتعدد الشاشات
- **بحث فوري موحّد:** البحث في الملفات المربوطة بالصناديق، الملاحظات الملتقطة، والمهام عبر اختصار لوحة مفاتيح.
- **وعي كامل بالشاشات المتعددة (Multi-Monitor Layout Persistence):** حفظ مواقع وأحجام الصناديق نسبةً إلى كل شاشة؛ وعند فصل شاشة خارجية تتكيّف الصناديق تلقائيًا، ثم تعود لمواضعها الدقيقة عند إعادة توصيلها.

### د. دعم كامل للعربية (RTL) والإنجليزية (LTR)
- واجهة كاملة باللغتين العربية والإنجليزية.
- تبديل فوري للغة واتجاه الواجهة (`RTL` ↔ `LTR`) دون الحاجة لإعادة تشغيل البرنامج.
- معالجة صحيحة لأسماء الملفات والمسارات العربية والإنجليزية والمختلطة.

## 4. ما لا يفعله المشروع (Out of Scope / Non-Goals)

حفاظًا على بساطة المشروع، خفّته، وأمانه، **لن يفعل المشروع** الأمور التالية:

1. **لا يستبدل مدير ملفات النظام أو غلاف سطح المكتب (Not a Shell Replacement):**
   - لن نستبدل `Windows Explorer` أو `macOS Finder` أو بيئة سطح المكتب في `Linux`. البرنامج يعمل كطبقة تنظيم مساعدة فوق النظام.
2. **لا حسابات مستخدمين ولا سحابة إجبارية (No Cloud Accounts or Telemetry):**
   - لا يوجد تسجيل دخول، ولا خوادم مركزية، ولا جمع بيانات استخدام (Telemetry).
3. **لا حذف تلقائي أو غير قابل للاسترجاع لملفات المستخدم:**
   - لا يقوم البرنامج أبدًا بحذف أي ملف من جهاز المستخدم تلقائيًا أثناء الفرز أو عند إلغاء ربط صندوق.
4. **لا فهرسة شاملة لكامل القرص الصلب في الخلفية:**
   - البرنامج يراقب فقط المجلدات التي يربطها المستخدم بوضوح داخل الصناديق، ولا يمسح كامل الأقراص حتى لا يستهلك البطارية أو المعالج.
5. **لا مدير كلمات مرور في المراحل الأساسية:**
   - التركيز ينصبّ على تنظيم شاشة سطح المكتب، الملفات، المهام السريعة، والكبسولة التفاعلية.
6. **لا تطبيقات للهواتف المحمولة (Android / iOS):**
   - المشروع مخصّص حصريًا لأنظمة سطح المكتب الثلاثة: **Windows، macOS، Linux**.
