# سجل القرارات المعمارية (Architecture Decision Records — ADRs)

> **الحالة الحالية لجميع القرارات:** ✅ **معتمد من مالك المشروع (2026-11-12)**  
> **حالة الاختبار:** **«لم يُختبر»** (لم يُكتب الكود بعد).
